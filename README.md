# Student Wallet AI — Updated MVP

This ZIP contains a Flutter source project for an Android-first local prototype.

## Included in this update
- Income and expense records
- Required description and positive amount validation
- Category, date, payment method, wallet/account and optional notes
- Transaction list with filtering, edit and delete
- Dashboard with balance, total income/expense and current-month budget progress
- Monthly budget and savings target settings
- Local on-device persistence with SharedPreferences
- Codemagic workflow that runs `flutter analyze`, `flutter test` and builds a release APK

## Not included yet
AI transaction parsing, voice entry, sign-in, cloud sync/backup, receipt OCR, multi-currency conversion, biometric lock, and production-grade financial security are not implemented. Do not use this prototype as the only record of important financial data.

## Build
1. Extract the ZIP.
2. Upload the files and folders inside the project folder to the root of your GitHub repository (or replace the repository contents after keeping a backup).
3. In Codemagic, start the Android workflow.
4. Download the APK from the successful build artifacts.
5. Test adding/editing/deleting records and reopening the app.

The Android platform folder is generated by `flutter create . --platforms=android` during the Codemagic build.
